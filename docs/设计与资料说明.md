# 设计与资料说明

## 输入与边界

- 用户提供的 Word 文档介绍“红韵青岛·数智传薪”，参考结构为首页、人物四栏目、人物与红色地标双向关联、关于支部。
- `主题.txt` 要求围绕建党105周年、长征胜利90周年，贯通历史学习、红色故事宣讲和科研攻关。
- 用户确认：将参考支部“专硕第二”对应改为“学硕第三”。后续用户明确要求扩展线上内容并推送 `main`。
- 因此本站统一使用“山东大学计算机科学与技术学院学硕第三党支部”。不修改原始 Word 文档和主题文件。

## 网站组织

名称“征途·薪火”连接历史道路与精神传承。深红承担主题表达，米白承载长文阅读，暗金用于时间与档案信息。首页使用泸定桥当代实景并标明来源，避免用生成画面冒充历史影像。

页面路径为 hash 路由，可直接分享具体人物、故事和地标，无需服务器重写规则；相对资源路径适配 GitHub Pages 项目目录。

## 长征沙盘整合

本地保留用户指定的 nova-fable/wanli-trail 全部源码、数据、测试和文档。由根构建脚本调用其 Vite 构建，将产物放到 `dist/trail/`。门户通过 iframe 和独立窗口两个入口访问，不需要远程托管原站。

门户首页的四路预览从同一份上游航点导出，不另造路线数据。门户的省级底图本地保存；沙盘仍按上游设计使用联网底图。沙盘的完整数据说明见 `vendor/wanli-trail/docs/`。

## 内容维护

- 支部信息、实际活动、照片和作品：`js/config.js`。
- 内容归一入口：`js/catalog.js`；地点和专题筛选字段由该模块定义。
- 全国人物与故事：`js/history-expansion.js`、`js/march-expansion.js`、`js/march-classics.js`、`js/science-expansion.js`、`js/sdu-history.js`、`js/qingdao-reviewed.js`。
- 讲话和案例：`js/speeches.js`、`SCIENCE_CASES`。
- 每个模块的来源引用都由 `npm run check:content` 自动检查。
- 来源与肖像归属：`docs/*-research.md`、`docs/*-photo-credits.md`、`THIRD_PARTY.md` 和网站“内容来源”页。
- 不展示虚构人数、访问量、获奖、科研成果或已举办活动；浏览器中的个人记录也不作为支部成果统计。

## 本机记录的边界

localStorage 用于已读状态、个人手记、攻关计划和宣讲草稿，不提供跨设备同步和共享后台。导出是 UTF-8 Markdown，内容会转义后呈现在网页，避免将用户输入作为 HTML 执行。删除后可即时撤销。网页无法写入的存储环境会明确提示并保留导出能力。
