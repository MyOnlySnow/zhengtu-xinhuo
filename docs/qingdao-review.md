# 青岛人物资料复核记录

核对日期：2026-11-11。新增文件：`js/qingdao-reviewed.js`。它不修改旧的 `js/qingdao.json`，而是导出 `QINGDAO_OVERRIDES`、`QINGDAO_SOURCES` 和一篇独立的 `QINGDAO_STORIES`，供应用在载入旧资料后按人物 ID 覆写文字字段。覆盖对象严格只含 `stories`、`timeline`、`summary`、`sourceIds`，因此原图和地标仍由旧数据保留。

## 核心口径

- 六位人物均至少有5条时间线节点、2条150—220字的原创短故事和2条以上实际核对的来源。短故事只写可追溯的行动、组织和结果，不补写小说式对白、心理活动或电影场景。
- 邓恩铭的青岛组成立采用1923年8月的国家民委资料；地方资料对1923年8月至1924年间的表述有差异，正文采用注明来源的口径。1928年春任青岛市委书记、1928年底或1929年初被捕的资料表述不同，时间线专门保留说明，不把不同月份拼成单一精确叙述。
- 李慰农的青岛工作、1925年7月26日被捕和7月29日在团岛牺牲，使用共产党员网和法院党史资料共同核对。旧资料中“陈独秀含泪”“狱中场景”等未经同一来源交叉确认的戏剧化细节没有写入。
- 周浩然的官方校史资料记载1933年加入青岛左联，1936年进入国立山东大学旁听，1937年参加中华民族解放先锋队并返乡开展抗日，1939年加入中国共产党并任即墨县委组织部长，1939年9月牺牲。原资料中的“1937年加入中国共产党”已更正；《汽笛》以1933年青岛左联和汽笛文艺社资料为依据，不写工棚聊天等虚构场景。
- 许振超的口径按资料年份分开：2012年页面记载团队“先后8次”刷新纪录；新华社2024年人物报道明确为2003年首次、此后又8次，即累计9次；2024年国家荣誉公示和主席令核对“人民工匠”称号。避免将“2003年八次/九次”混为一个数字。
- 张连钢的“时代楷模”荣誉主体是2013年以来的“连钢创新团队”，不是把团队成绩全部归于个人。正文采用山东省委宣传部、人民日报和共产党员网关于系统研发、模拟实测、2017年投产、5G与绿色码头等材料。
- 高维玉的村级数据区分来源和范围：2020年《青岛日报》写合村并居、6000余亩区域产业集群和村民人均增收；2025—2026年报道写全村葡萄规模超过1500亩、村集体经济由2014年零收入达到240万元、村民年均收入3.6万元。正文不把区域集群年产值直接写成沟东新村单村产值。
