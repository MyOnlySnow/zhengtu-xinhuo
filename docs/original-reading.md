# 原文阅读与版权反馈

2026-11-12更新：故事页将全部对应资料的标题、发布机构、日期和完整原文链接前置；讲话列表突出官方全文按钮，讲话详情先展示全文入口，再展示本站导读。本站整理文章、研学分析与原发布页全文明确区分。

故事、讲话、内容来源页显示用户指定的提示：“如侵犯版权，请联系管理员进行删除。”管理员入口使用本仓库的GitHub Issue模板，可提交删除、署名更正等请求。表单公开可见，提示不提交个人敏感材料；网站阅读不要求登录，提交GitHub反馈需要登录。

本轮核对了7个讲话原发布页面的标题、时间和发布来源；没有取得这些现代作品可在本站整篇复制的明确授权，不将原发布页面可公开访问视为转载授权。现代故事报道也未因加入上述提示而改为整篇复制。已有研学正文和完整导出功能保留。

核对依据：

- [国家版权局：关于规范网络转载版权秩序的通知](https://www.ncac.gov.cn/xxfb/tzgg/201504/t20150422_50363.html)：网络转载涉及许可、报酬和署名，法律法规另有规定除外；注明来源并非一般性的免授权条件。
- [现行著作权法](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：第24条列举法定使用情形，第26条规定许可使用。政府网站发布的材料不因此自动等同于第5条排除保护的法律法规及具有立法、行政、司法性质的官方文件。
- [新华网版权声明](https://www.xinhuanet.com/copyrightad.htm)：有权使用或拥有版权的作品有授权要求，转载来源标注本身不代表已取得本站的使用许可。

本地验证：构建与内容检查通过，15项沙盘测试和22项门户浏览器测试通过。对23篇故事、7篇讲话、讲话列表和来源页，在320/390/768/1440px四种宽度下共128组页面检查，无横向溢出及脚本异常；逐页验证原文入口和版权提示。反馈表模板随源代码推送后生效。
