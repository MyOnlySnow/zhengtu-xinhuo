# 全国人物与故事扩充：资料核对记录

核对日期：2026-11-11。对应数据文件为 `js/history-expansion.js`，包含7位人物、14篇人物短故事、7篇约630—690字的分节共读文章、7个研学地标、23条公开来源。

各篇共读文章先安排4节具体史实或纪念实践，最后单列“今天的行动”，使史料概述与本站教学设计清楚分开。每节均保留 `sourceIds`，页面可以展示所有原文链接。本文不镜像外部文章，不为历史人物编造对白；读者可点击原始报道继续阅读全文。

人物的 `province / city / district` 表示本站选择的主要事迹发生地，**不是籍贯**。赵一曼的主要事迹地区为黑龙江哈尔滨尚志一带，而关联纪念馆在四川宜宾，地标另有自己的地区属性。张桂梅出生地与工作地也分开处理。各坐标为市县或场馆所在区域的近似研学示意，不是经过测绘的导航位置。

## 资料使用方法

- 采用原创概述和学习引导，全文阅读交由原发布平台。
- 不使用未确认身份的肖像图，不以生成图像冒充历史人物。
- `sourceIds` 同时保存在人物、短故事、长故事分节和地标中，便于逐项核对。
- 当代实践建议与历史事实分节显示，不把假设情境当作已发生的故事。
- 数据无本支部成果、人数、获奖、宣讲作品等虚构记录。
