## 史料与篇幅

- 每位人物、故事、地点与案例均关联已核对的来源 ID；构建前执行 `npm run check:content`，检查来源链接、引用、地域元数据、章节结构与关联目标。
- 七篇长征专题单篇超过1500个中文字符，其中包含半条被子、陈树湘和泸定桥三篇原故事的详尽改写版本。正文为跨来源原创归纳，不转载完整已发表文章；完整原文通过来源链接阅读。
- 所有故事具有章节目录、研学问题、宣讲提纲和可下载的完整 Markdown 研学稿；科研专题的建议明确标为教学设计。
- 人物照片逐张看图核对，地区按主要事迹或科研地点筛选，不把籍贯与工作地混为一谈；科研场馆、学校和村庄标明公众访问提示。
- 本支部活动和成果数据仍留空，不虚构本支部活动、获奖、访问量或科研成果。
- `.github/workflows/pages.yml` 执行内容检查、上游沙盘测试和无头浏览器端到端检查。
