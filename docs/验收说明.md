## 已执行检查

使用 Node.js v22.23.2，Chromium / Playwright 1.65.0。

```text
npm run build
  Vite 构建成功，门户与长征沙盘产物进入 dist/

npm test
  wanli-trail：15 / 15 项通过
  门户真实浏览器：10 / 10 项通过
```

浏览器检查覆盖：

1. 首页与全部主要页面、支部名称、图片加载和桌面横向边界。
2. 人物搜索、四个详情栏目、人物→地标深链接、可见地图标记、地标→人物返回。
3. 已读状态与手记刷新恢复，HTML 输入作为文本呈现，Markdown 导出，删除与撤销。
4. 微党课补充草稿自动保存、刷新恢复，提纲导出含用户补充与官方来源。
5. 科研攻关计划保存，更新阶段并刷新恢复。
6. 自测按不同答案产生相应正确题数与解释。
7. 沙盘“自由探索”“开始演示”、地图初始化、时间轴键盘跳转。
8. 390×844 手机视口下的导航、人物、地图、故事、表单、关于页无横向溢出。
9. 模拟 GitHub Pages `/zhengtu-xinhuo/` 项目子路径；阻断外网后门户、省界/地标与沙盘本地入口仍可加载。
10. 浏览器禁止持久存储时，明确提示、保留当前会话记录并可导出。

画面检查另外核对了桌面首页、手机首页、手机地图和手机沙盘。地图已补充本地区界和区域名称，选中地标的标签与图标不再重叠遮挡。截图保存在 `docs/screenshots/`。

另外在实际联网的浏览器中确认长征沙盘成功加载在线地图瓦片，不仅验证了断网时的本地入口。

保存初始版本前，逐项比较门户入口、样式、脚本和素材：36 个源文件均与 `dist/` 中的对应文件一致。

## 明确保留的边界

- 支部真实照片、宣讲作品和科研成果尚未提供，页面说明待整理；配置入口为 `js/config.js`。
- 个人记录保存在当前浏览器，不是支部共享后台，不跨设备同步；提供导出备份。
- 长征沙盘路线为上游近似航点，底图以及官方资料/影像外链需要网络。门户自己的地标边界和标记不依赖在线底图。
- 此处25项自动化检查针对本地构建与模拟子路径；真实线上部署另以 GitHub Actions 结果及网站实际访问情况验证。
- 上游可选3D模块构建出现大体积包提示；该模块为延迟加载，普通门户与二维沙盘构建通过。
