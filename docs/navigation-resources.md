# 导航与拓展资源整理

日期：2026-11-12。后续按用户要求删除首页与沙盘页重复的数字体验模块，更新说明如下。

## 栏目结构

主导航仅有“首页、学思践悟、拓展资源”。后两项同时提供栏目链接与独立展开按钮，桌面点击展开、键盘向下进入菜单，Escape关闭并恢复焦点；点击页面空白、切换栏目或改变屏幕布局会关闭菜单。1180像素及以下使用折叠菜单，下级菜单保留分组。

下拉菜单采用纸色浮层、分组底色、栏目说明和箭头；当前项以朱红边线、底色与加粗文字突出，悬浮和键盘焦点有独立反馈。手机改为上下分组、组内双列，保留较大的点击区域，并支持窄屏内部滚动和减少动态效果偏好。

- 首页：保留专题、路线概览与人物故事，删除“循着地图，走进历史现场”整栏；下部完整展示支部介绍、建设思路、活动与作品。旧 `#/about` 自动跳转 `#/?section=branch` 并聚焦支部标题。
- 学思践悟：分为“学·理论与历史”和“做·实践与体会”，包含重要讲话、人物故事、故事共读与宣讲、典型案例、科研攻关计划、研学自测、我的研学。
- 拓展资源：主按钮和页脚同名入口直接进入 `#/trail` 长征沙盘；下级“全部拓展资源”保留 `#/resources` 汇总页。菜单分为地图与数字体验、资料与出处。旧 `#/trail?mode=resources` 自动跳转资源汇总页。

## 路径导航与首页

全站在非首页统一呈现当前位置，始终从“首页”开始，最后一项为当前页且不可重复点击。列表、人物、故事、讲话、案例、地图、手记、自测与长征的三种视图均覆盖；主导航同步高亮所属栏目。长征入口为“首页 / 长征沙盘”，切换年表或轻量地图后继续添加对应层级；讲话、人物及科研详情使用“首页 / 学思践悟 / 栏目 / 详情”。旧关于页仍定位首页支部区域。切换页面立即回到顶部，防止旧页面滚动位置影响路径展示。

首页保留原有纸色与朱红风格，缩短首屏主视觉，下方直接呈现“学一段历史、讲一个红色故事、攻一个科研难题”三步入口。专题与人物卡片调整间距、字号和照片高度；重要讲话与三篇故事合并为双栏共读区，替代独立大横幅和底部重复的完整路径介绍。手机改为上下排列。已删除的首页数字体验模块和沙盘“数字研学拓展”栏目不再出现。

## 数字体验

拓展资源页集中提供三个本站入口：四路红军长征沙盘、毛主席足迹地图、轻量长征路线图；体验卡片仅保留站内入口，删除GitHub“源码与说明”按钮。首页不再重复展示数字体验卡片，沙盘页已删除“数字研学拓展”整栏，仍可使用三种站内地图视图。长征战役立体推演、哈达铺红军街已从体验卡片和网站来源页的候选项目列表移除。沙盘页归属保留为作者名称及本地适配说明，详细代码归属集中在“内容与项目来源”页面。

轻量路线图复用 `youxuels/long-march-map` 单页交互，固定版本 `f64998f0347dd1d8538937c61c2e7f37550ced71`，上游README声明MIT。原始文件保存在 `vendor/long-march-map/`；未导入Git历史，不改变本仓库提交作者。发布适配由 `scripts/build-light-march.mjs` 执行：

- 节点与资料来自本站 `js/data.js` 的9个历史节点，路线与主沙盘采用同一份四路红军航点。移除上游原14节点、未核对引语和统计口径。
- 保留地图定位、时间线、逐步播放、键盘操作与来源入口；区分1935年中央红军到达陕北与1936年三大主力会师。
- Leaflet使用本站文件，默认本地省界轮廓，不请求外部地图瓦片。可选择在线OpenStreetMap街道底图；未联网时节点与示意路线仍可使用。
- 发布到 `dist/light-march/`，通过 `#/trail?mode=light` 内嵌。同目录保留上游README、MIT声明和适配说明。
