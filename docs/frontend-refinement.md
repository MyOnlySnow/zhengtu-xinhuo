# 前端优化记录

日期：2026-11-12。发布沿用现有GitHub Pages工作流。

本记录保存此前样式优化过程；其后已整理为三个主导航，删除外站战役与街区入口，并将轻量路线图内嵌。当前结构见 [导航与拓展资源整理](navigation-resources.md)。

## 页面调整

- 保留纸色、深红和书刊式标题，统一正文对比、留白、按钮、卡片边框及圆角。
- 首页主视觉调整图片叠色与文字层次；数字研学馆紧接主视觉展示，提供足迹年表、战役推演、哈达铺街区三个直接入口，并保留全部体验入口。
- 首页合并重复的三条路径介绍，完整路径仍可在页面下部和学思践悟栏目阅读。
- 统一人物、故事、讲话、案例、来源及手记页面样式。长文正文桌面为17px、手机为16px，保留完整章节、来源和导出功能。
- 1180px及以下使用折叠菜单；点击导航后收起，Escape关闭后回到菜单按钮。窄屏下卡片自适应、长征节点采用纵向时间线，来源提交号可换行。

三个体验封面为本项目原创SVG示意图，位于`assets/illustrations/`，不依赖外部图片服务。路线图与战役地形用于视觉引导，哈达铺封面为明确标注的概念示意，均不作为历史测绘或旧址实景资料。

## 验证

环境：Node.js v22.23.2、Playwright 1.65.0 / Chromium。

- `npm run build`：通过。
- `npm test`：内容检查通过；15项沙盘测试、22项门户浏览器测试通过。新增检查覆盖首页体验链接、320/390/768/1024px导航展开、Escape焦点恢复、导航跳转及布局。
- 布局检查：320、390、650、768、1024、1180、1440px共7种宽度，遍历首页、人物、故事列表、重要讲话、典型案例、泸定桥故事、内容来源、手记、攻关计划、数字研学馆、地图、关于支部12类页面，共84组；无横向溢出或脚本异常。
- 自动化测试继续覆盖本机手记持久化、完整正文导出、地图联动、沙盘操作及GitHub Pages项目子路径。

外部战役推演与三维街区仍在原站打开；本轮验证入口地址和跳转属性，未将外部体验迁入本站。
